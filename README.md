# Run with Confidence

A responsive web app that lets people:

- choose a language from a list
- enter their name for a personal motivation card
- see a short phrase with pronunciation, English translation, and an image
- use the experience on desktop and mobile devices

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Push the project to GitHub.
2. Import the repository in Vercel.
3. Vercel will use the existing build settings from `vercel.json` and build the app from the `dist` folder.
